# Cast Hub (`cast_hub`)

FastAPI Cast / FHIRcast hub. Run standalone:

```bash
pip install -e ../cast_py_client
pip install -r requirements.txt
python cast_hub.py --port 2018
```

Admin: http://127.0.0.1:2018/api/hub/admin

See [docs/CAST-HUB-README.md](docs/CAST-HUB-README.md) and [azure-webapp.md](azure-webapp.md).
